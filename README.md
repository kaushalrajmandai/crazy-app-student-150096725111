# ⚡ Neon Particle Sandbox ⚡

A cyberpunk canvas where your mouse turns into a firework factory.

## How to Play
- **Move** the mouse to leave glowing particle trails
- **Click** for an explosive shockwave with bass + synth sound
- **Hold** the mouse for continuous chaos
- Click once first so the browser allows sound

## Secret Features
- **G**: glitch mode, with a screen color flip and noise bursts
- **SPACE**: toggle gravity so particles rain down
- **K**: signature move that spells KAUSHAL in neon with a burst for each letter
- Built-in `console.assert` tests; open the Console to check they pass silently

Built with plain HTML, CSS and JavaScript in a single file.
